# مدير أوردرات بوسطة الذكي (Bosta Smart Order Manager)

تطبيق Desktop مكتبي ذكي مصمم خصيصاً للتجار ومسؤولي الشحن لقراءة رسائل العملاء (واتساب / فيسبوك / ماسنجر) وفحصها وإضافتها تلقائياً إلى شيت بوسطة المعتمد `Bosta Upload Template AR V3.5.xlsx`.

---

## 🌟 أهم المميزات:
1. **نظام هجين فائق السرعة (صندوق رسائل ذكي + نظام حقول مباشر):**
   - بمجرد لصق الرسالة (`Ctrl+V`)، يتم استخراج كافة البيانات وتعبئة الحقول فوراً.
   - يمكنك تعديل أي حقل بمرونة وسرعة قبل الحفظ.

2. **كشف التكرار الذكي (Duplicate Detection):**
   - يفحص رقم الهاتف والاسم مقابل جميع الأوردرات المسجلة في الشيت (أكثر من 149 أوردر).
   - إذا كان الرقم مكرراً، ينبهك برقم السطر واسم العميل السابق وكود الطلب، مع إمكانية المتابعة أو الإلغاء.

3. **فحص أرقام الهواتف والأرقام الناقصة:**
   - فحص شبكات المحمول المصرية (010, 011, 012, 015).
   - عداد حي للأرقام (11/11 أخضر، أو تنبيه بالأحمر لو ناقص).
   - معالجة الأرقام المكتوبة بدون صفر في البداية تلقائياً.
   - تحويل الأرقام المكتوبة بالعربي (٠١٢٣٤٥٦٧٨٩) تلقائياً إلى أرقام قياسية.

4. **مطابقة المحافظات والمناطق المعتمدة لبوسطة:**
   - يحتوي على كافة محافظات بوسطة الـ 26 ومناطقها الرسمية.
   - ذكاء جغرافي: إذا كتب العميل "طنطا" يستنتج المحافظة "الغربية"، وإذا كتب "المعادي" يستنتج "القاهرة".

5. **الإضافة التلقائية للشيت:**
   - يضيف الطلب الجديد مباشرة في نهاية ورقة العمل `Add orders here` دون المساس بالتنسيق أو الصيغ.
   - ترقيم تلقائي متسلسل لأكواد الطلبات (ORD-150 وما يليه).
   - جدول حي يعرض آخر الطلبات المضافة مع إمكانية البحث الفوري.

6. **يعمل بدون إنترنت (أوفلاين) + خيار الذكاء الاصطناعي (Gemini):**
   - المحلل المدمج فائق السرعة يعمل 100% محلياً بدون إنترنت ومجاناً.
   - متاح خيار استخدام Gemini AI للرسائل المعقدة عبر إدخال مفتاح API في الإعدادات.

---

## 🚀 طريقة التشغيل:
- **من سطح المكتب:** انقر مرتين على أيقونة `مدير أوردرات بوسطة الذكي`.
- **أو من سطر الأوامر:**
  ```bash
  ./run.sh
  ```

## ⌨️ اختصارات لوحة المفاتيح:
- `Ctrl + Return`: حفظ الطلب في الإكسيل فوراً.
- `Ctrl + N`: مسح الحقول وبدء طلب جديد.
